NeedNow Recommendation System Architecture (MVP)
Goal

Our goal is not to recommend products based only on category.

Instead, we want to recommend products that a user is most likely to interact with or purchase, based on their past behavior.

Example:

User interacts with:

MacBook Air
AirPods Pro
Magic Mouse

Instead of recommending random laptops, the system should recommend:

Magic Keyboard
Mac Mini
Apple Watch
USB-C Hub

This recommendation should improve automatically as more users interact with products.

What does Implicit do internally?

This is the important part.

It does NOT compare every product with every other product manually.

Instead it uses

ALS learns hidden patterns called latent factors.

Limitation (Cold Start Problem)

If a brand-new product has never been viewed, clicked, added to cart, or purchased, Implicit has no interaction data for it, so it cannot recommend it effectively.

Similarly, if a new user has no interactions, the model has no basis for personalization. Common solutions are:

Show trending or popular products.
Ask a few onboarding preference questions.
Use AI conversation history to bootstrap recommendations.
